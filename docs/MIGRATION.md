## 四、文章字段映射

| 新字段 | 来源 / 规则 |
| --- | --- |
| `title` | frontmatter `title` |
| `slug` | `permalink` 去掉 `/pages/` 与末尾 `/`（如 `/pages/7634a/` → `7634a`）；**冲突**时后者加 `-2`（`/pages/43bd14/` 有 1 组冲突） |
| `created_at` | `date`，容错解析 `2022-2-24 18:00:00` 等；缺失则取文件名前缀排序后的相邻日期，仍无则取 `2020-01-12`（站点最早日期）并记入报告 |
| `summary` | 取正文去 Markdown 标记后的前 120 字 |
| `content` | 去 frontmatter；`</br>`、`<br>` → 空行/换行；其余原样 |
| `status` | `published`（源站无草稿概念） |
| `category_id` | 按第三节映射 |
| `tag_ids` | frontmatter `tags`；**丢弃空标签**（约 106 处）；与分类同名的标签保留 |
| `is_top` | frontmatter `sticky` 存在则 `true`（7 篇） |
| `cover_image` | 空 |
| 忽略 | `titleTag`、`comment`、`editLink`、`sidebar`、`author`、`pageComponent`、`article` |

## 七、导入脚本

- 位置：`tools/import_vuepress.py`（独立脚本，不进后端）。
- 通过**后台 API**写入（`/api/auth/login` 取 Token），不直接写库，保证与契约一致。
- 幂等：以 `slug` 判断，已存在则 `PUT` 更新，不重复创建；分类按 (`parent_id`,`name`) 复用。
- `--dry-run`：只解析并输出报告（分类树、将创建/更新/跳过的文章、日期修复、重名/冲突、缺失图片），**不调用任何写接口**。
- 导入后对账：源文章数 = 目标已发布文章数 + 跳过数；抽样比对 10 篇正文。
